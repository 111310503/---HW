# 數值微積分與蒙地卡羅高維積分實作

---

## 專案簡介
本專案使用純 Python 標準函式庫實作單變數與多變數的數值微分與積分，並比較**黎曼積分法**與**蒙地卡羅法**在面對高維度積分（1 維、2 維、5 維、100 維）時的效能與準確度差異。

## 實作功能清單
1. **單變數數值微分與積分**：使用中央差分法 (`diff_1d`) 與中點黎曼和 (`riemann_1d`)。
2. **單變數蒙地卡羅積分**：使用均勻隨機取樣估算面積 (`mc_integral_1d`)。
3. **n 變數數值微分（梯度）**：計算多元函數在指定點的偏微分向量 (`gradient`)。
4. **n 變數黎曼積分（超體積）**：實作 `integral(f, low, high)`，透過巢狀網格（`itertools.product`）計算 $n$ 維超體積，並內建防呆機制避免高維計算當機。
5. **n 變數蒙地卡羅積分（超體積）**：實作 `mc_integral(f, low, high)`，透過高維空間均勻隨機取樣估算超體積。
