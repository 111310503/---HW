# 數學、語言、機器與程式

## 從希爾伯特到圖靈的那些故事

> 以 Python 展現這些故事背後的程式

本書串起了 20 世紀計算理論與電腦科學最核心的歷史脈絡：從數學家試圖「把所有數學證明自動化」的夢想開始，歷經夢想破滅、嚴謹定義出「什麼是計算」，接著延伸至程式語言的語法階層與演算法效率的極限，最後落地為現代實體電腦與編譯器的完整藍圖。

## 第一階段：數學基礎危機與「可計算性」的定義（第 01–04 章）

本階段探討計算理論的第一大支柱——**可計算性（Computability）**，劃出數學推理與電腦能力的絕對邊界。

| 章節主題 | 人物與核心概念 | 在計算理論中的關鍵意義 | Python 實作視角 |
| :--- | :--- | :--- | :--- |
| **01-希爾伯特的問題** | **大衛·希爾伯特（David Hilbert）**<br>形式主義與判定性問題（Entscheidungsproblem） | 1900 年提出數學完全形式化綱領，追求公理系統的一致性、完備性與可判定性；1928 年追問是否存在一套「機械化程序」能判定所有數學命題的真偽，催生了計算機科學的源頭問題。 | 實作命題邏輯真值表（Truth Table）或簡易自動推論器，展示「機械化證明」的概念。 |
| **02-哥德爾的定理** | **庫爾特·哥德爾（Kurt Gödel）**<br>不完備定理與哥德爾編碼 | 1931 年透過「哥德爾編碼」將符號轉為自然數，讓系統能討論自身，證明任何包含基本算術的一致性公理系統，都存在「為真但無法證明」的命題，宣告希爾伯特的絕對完備夢想無法實現，也首次揭示「程式與資料同源」。 | 撰寫哥德爾編碼／解碼器，或實作能印出自身原始碼的 **Quine** 程式，體驗自指（Self-reference）。 |
| **03-丘奇的函數** | **阿隆佐·丘奇（Alonzo Church）**<br>$\lambda$ 演算（Lambda Calculus） | 1936 年從「純函數定義與代換（$\beta$-歸約）」的角度刻劃可計算性，僅靠函數即可建構自然數（丘奇數）與遞迴（Y Combinator），率先證明判定問題無解，成為現代函數式程式語言（Lisp、Haskell 與 Python `lambda`）的理論基石。 | 使用 Python `lambda` 實作丘奇數、布林邏輯、Y Combinator，以及簡易 $\lambda$ 演算直譯器。 |
| **04-圖靈的機器** | **艾倫·圖靈（Alan Turing）**<br>圖靈機與停機問題 | 1936 年以「無限紙帶＋讀寫頭＋狀態轉移」建立抽象計算模型，提出**通用圖靈機**（儲存程式概念），並以反證法證明**停機問題（Halting Problem）**不可判定。其計算能力與 $\lambda$ 演算完全等價（**Church-Turing 論點**）。 | 用 `dict` 與 `list` 實作圖靈機模擬器（例如辨識 $a^n b^n c^n$），並以程式碼重現停機問題的反證邏輯。 |

## 第二階段：形式語言、計算複雜度與實體電腦（第 05–08 章）

本階段涵蓋**形式語言與自動機**、**計算複雜度**，並將抽象理論一路串接回真實世界的硬體與編譯器。

### 05-喬姆斯基的語法

**諾姆·喬姆斯基（Noam Chomsky）**在 1956 年提出**形式語言層級（Chomsky Hierarchy）**，將文法由弱到強分為四類，並精準對應到四種抽象計算機器：

1. **正則文法（Regular, Type 3）** $\leftrightarrow$ 有限狀態機（FSM）
2. **上下文無關文法（Context-Free, Type 2）** $\leftrightarrow$ 下推自動機（PDA，現代程式語言剖析器的基礎）
3. **上下文有關文法（Context-Sensitive, Type 1）** $\leftrightarrow$ 線性有界自動機（LBA）
4. **無限制文法（Recursively Enumerable, Type 0）** $\leftrightarrow$ 圖靈機（Turing Machine）

```text
┌───────────────────────────────────────────────────────────┐
│  Type 0: 遞迴可枚舉語言 (Recursively Enumerable) - 圖靈機  │
│  ┌─────────────────────────────────────────────────────┐  │
│  │  Type 1: 上下文有關 (Context-Sensitive) - LBA        │  │
│  │  ┌───────────────────────────────────────────────┐  │  │
│  │  │  Type 2: 上下文無關 (Context-Free) - PDA       │  │  │
│  │  │  ┌─────────────────────────────────────────┐  │  │  │
│  │  │  │  Type 3: 正則語言 (Regular) - FSM        │  │  │  │
│  │  │  └─────────────────────────────────────────┘  │  │  │
│  │  └───────────────────────────────────────────────┘  │  │
│  └─────────────────────────────────────────────────────┘  │
└───────────────────────────────────────────────────────────┘
```

在上圖中，最內圈的 **Regular（正則語言）**表達能力最受限，卻最容易高效剖析；最外圈的 **Recursively Enumerable（遞迴可枚舉語言）**則等價於圖靈機所能識別的所有語言——這張階層圖正好銜接了第 04 章的機器模型與第 05 章的語法理論。

* **Python 實作視角**：實作有限狀態機（DFA）、正規表達式比對，以及用遞迴下降法（Recursive Descent）撰寫簡易的 CFG 語法剖析器。

### 06-庫克的證明

**史蒂芬·庫克（Stephen Cook）**在 1971 年提出**庫克-列文定理（Cook–Levin Theorem）**，證明**布林可滿足性問題（SAT）**為第一個 **NP-Complete（NP 完全）**問題——任何屬於 $NP$ 類的問題（其解可在多項式時間內驗證），皆可在多項式時間內歸約（Reduce）為 SAT 問題。

這標誌著計算理論從「**能不能算**（可計算性）」跨入「**算得快不快**（計算複雜度）」，並引出電腦科學最著名的未解之謎：$P \stackrel{?}{=} NP$。

* **Python 實作視角**：實作 3-SAT 的暴力求解器與多項式時間驗證器，直觀比較問題規模擴大時的「指數爆炸」與快速驗證的差異。

### 07-馮紐曼的報告

**約翰·馮紐曼（John von Neumann）**在 1945 年撰寫《EDVAC 報告書初稿》（*First Draft of a Report on the EDVAC*），將圖靈的「通用圖靈機」與布林邏輯轉化為實際可建造的電子硬體藍圖（包含運算器 ALU、控制器、記憶體與輸入／輸出裝置），正式確立「**程式與資料同存於記憶體**」的現代電腦架構。

* **Python 實作視角**：以 Python 撰寫極簡虛擬 CPU 模擬器，完整演示「擷取（Fetch）$\rightarrow$ 解碼（Decode）$\rightarrow$ 執行（Execute）」的指令週期。

### 08-從語言到機器

總結全書主線，串聯起數學邏輯、形式語言與實體硬體：說明人類撰寫的高階程式語言，如何經由**詞法分析（Lexer，基於正則文法）**、**語法剖析（Parser，基於上下文無關文法）**，再透過編譯或直譯技術，一步步轉譯成馮紐曼架構硬體能直接執行的機器指令。

* **Python 實作視角**：整合前面章節的元件，實作一個從原始碼、抽象語法樹（AST）到虛擬機器位元組碼（Bytecode）的迷你直譯器／編譯器管線。
